# EQUAL SURVIVAL: website cộng đồng

Web cho server Minecraft sinh tồn chill **EQUAL SURVIVAL**: trạng thái server, cách tham gia, lệnh, bảng xếp hạng Build Points, ảnh, góp ý, tin tức/event và trang admin.

- **Cài đặt và kết nối plugin:** xem [HUONG-DAN.md](HUONG-DAN.md)
- **Dành cho AI (ChatGPT/Codex/Claude) sửa code:** xem [AGENTS.md](AGENTS.md)

Chạy thử trên máy (cần JDK, có sẵn `jwebserver`):

```bash
jwebserver -p 5173 -b 127.0.0.1 -d D:\webmc
```

Rồi mở http://localhost:5173.
